# 白翊言的物理手记

我是白翊言，2026 年 7 月起在教培机构担任物理教师。这里收录了我在零基础课堂使用的互动演示、个人经历，以及课堂之外写的一些工具。[访问我的主页](https://qidian2022.github.io/)

## 课堂实验

| 实验 | 可以做什么 |
| --- | --- |
| [凸透镜成像](labs/convex-lens.html) | 拖动物体或透镜，观察三条特殊光线和像的位置。 |
| [日月食与水星凌日](labs/celestial-shadows.html) | 切换三种天象，对照天体的位置与观测者的视野。 |
| [潜水蛙的压强实验](labs/diving-frog.html) | 改变下潜深度和液体，比较液体压强。 |

三个 HTML 实验都可以从首页下载，在浏览器中离线打开。首页另有一个单摆实验，可以调节摆长并读出小角度近似下的周期。

## 本地查看

直接打开 `index.html`，或在仓库目录运行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`。GitHub Pages 直接发布 `main` 分支根目录。
