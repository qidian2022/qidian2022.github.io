# 白翊言的物理手记

我是白翊言，2026 年 7 月起在上海家辉教育担任超优物理教师。这里收录了我的课堂实验、个人经历、软件项目和户外相册。[访问我的主页](https://qidian2022.github.io/)

## 课堂实验

| 实验 | 可以做什么 |
| --- | --- |
| [阿基米德浮沉实验](labs/buoyancy.html) | 改变密度，观察物体浮沉。 |
| [透镜成像](labs/convex-lens.html) | 切换凸透镜和凹透镜，比较特殊光线与像。 |
| [日月食与水星凌日](labs/celestial-shadows.html) | 切换三种天象，对照天体的位置与观测者的视野。 |
| [潜水蛙的压强实验](labs/diving-frog.html) | 改变下潜深度和液体，比较液体压强。 |
| [杠杆平衡](labs/lever.html) | 改变力与力臂，检验平衡条件。 |
| [串并联电路](labs/circuits.html) | 比较串并联电路的电流和电压。 |

六个实验均可从首页下载，在浏览器中离线打开。首页另有一个单摆实验，可以调节摆长并读出小角度近似下的周期。

## 本地查看

直接打开 `index.html`，或在仓库目录运行 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`。GitHub Pages 直接发布 `main` 分支根目录。
